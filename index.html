Sobre o Alerta SST

Objetivo

Promover a cultura de prevenção por meio do registro de perigos, condições inseguras e quase acidentes, com acompanhamento das medidas corretivas.

Como funciona

1. Registre uma ocorrência. 2. Consulte o painel. 3. Acompanhe a situação e documente as providências. 4. Exporte os dados para análise.

Privacidade e limitações

Os dados são armazenados somente no navegador deste dispositivo (localStorage). Não há contas, servidor, envio automático, nem comunicação entre dispositivos. A opção anônima apenas omite o nome no registro; não representa um canal corporativo de denúncia com garantias formais de anonimato. Fotografias e descrições ficam acessíveis a quem utilizar este navegador. Limpar os dados do navegador pode eliminar os registros.

O sistema é um protótipo educacional, não substitui o gerenciamento de riscos ocupacionais, procedimentos de emergência, inspeções técnicas ou obrigações legais aplicáveis.

Instalação

Publique os arquivos em um serviço HTTPS (por exemplo, GitHub Pages) e utilize a opção “Adicionar à tela inicial” ou “Instalar aplicativo” no navegador compatível. Abrir o arquivo HTML diretamente também permite testar as funções principais, mas a instalação PWA e o modo offline exigem HTTPS ou localhost.
